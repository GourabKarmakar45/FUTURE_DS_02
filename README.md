# 📊 Customer Retention & Churn Analysis Dashboard

## 🔍 Project Overview

This project focuses on analyzing customer churn and retention patterns using Python and Power BI. The goal is to identify why customers leave and provide actionable insights to improve retention.

---

## 🎯 Objectives

* Analyze customer churn rate
* Identify high-risk customer segments
* Understand customer lifetime behavior
* Provide business recommendations to reduce churn

---

## 🛠️ Tools & Technologies

* Python (Pandas, NumPy, Matplotlib, Seaborn)
* Power BI
* CSV Dataset

## 📊 Key Insights

* Customers with low engagement are more likely to churn
* Certain subscription plans show higher churn rates
* New customers churn faster than long-term users
* Regional differences impact churn behavior

---

## 📈 Dashboard Features

* KPI Metrics (Churn Rate, Total Customers, Avg Lifetime, Avg Usage)
* Churn Distribution
* Churn by Plan & Region
* Customer Lifetime Analysis
* Cohort Analysis
* Interactive Filters

---

## 🚀 How to Run

1. Clone the repository
2. Install dependencies:
   pip install -r requirements.txt
3. Run Python script:
   python churn_analysis.py
4. Open Power BI file to explore dashboard
